# Getting Started

## Firmware
1. Install [PlatformIO](https://platformio.org/).
2. Flash `firmware/main.cpp` to your ESP32 board.

## Mobile App
1. Install Node.js and React Native CLI.
2. Navigate to `app/react-native/`.
3. Run `npm install` and `npm run android`.

## Simulation
Run `python sim/ev_simulator.py` to test the dashboard without hardware.
